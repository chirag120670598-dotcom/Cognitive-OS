# AI-Generated AGI Architecture Proposals

## Overview
This research packet collects, preserves, and compares AGI architecture proposals generated by **8 distinct AI systems**. Each system was given the same core prompt requesting a complete AGI architecture design covering memory, reasoning, learning, tool use, world modeling, safety, evaluation, runtime, multi-agent design, engineering feasibility, and originality.

## Collection Method
Each AI system was accessed through its public or authorized interface and given a standardized prompt (see prompts.md). Responses were collected in raw form with minimal cleaning (whitespace normalization only). No responses were edited for content.

## Headline Findings
1. Dual-process architectures dominate: 5/8 proposals feature some form of fast/slow or intuitive/deliberative processing
2. Safety is architectural, not additive: Most proposals embed safety at the architectural level rather than as a separate filter
3. Sparse computation is emerging: Two proposals (Mistral, DeepSeek) explicitly optimize for computational efficiency
4. Causal reasoning is the frontier: The most innovative proposals center causal discovery as the core cognitive capability
5. Modularity vs. monolith: The field is split between unified world-model approaches and modular microservice architectures
